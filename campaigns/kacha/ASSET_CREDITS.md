# Campaign emblem sources

These assets are not covered by the framework MIT code license.
All custom emblems come from Wikimedia Commons originals; no AI image generation.
Only raster conversion, uniform scaling and transparent square padding are applied.

The 810th patch is a real modern design, deliberately retained as an identity cue, not a 1989 insignia.
Other general departmental symbols are not represented as verified individual unit crests.

## Native WARNO resources

Texture_Division_Emblem_SOV_157MSD, Texture_Division_Emblem_SOV_AirForce and
Texture_Division_Emblem_US_2nd_Marine_Division are unchanged Eugen game resources.
