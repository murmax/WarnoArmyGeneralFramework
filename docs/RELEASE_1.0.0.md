# Release 1.0.0

The initial public source release contains the Python authoring framework,
textual compatibility profiles, small campaign examples and preparation /
publication helpers. It does not include the WPF editor or game-derived assets.

The native compatibility baseline is ModGen 201602. The complete build path
is verified locally with the installed game's official tools. Other game
versions and installation layouts may require adapter updates.

The companion Kacha V10 campaign is a self-contained Workshop item:
https://steamcommunity.com/sharedfiles/filedetails/?id=3811284575

V10 includes MiG-27/Su-25 air-support choices, separate Soviet Air Force
formations, transient AP locks, tracked carrier-wing withdrawal, continuous
cooperative attack routes and a five-turn deadline after carrier withdrawal.
Two turn-7 Soviet reserve battalions guard Balaklava; the naval reserve remains
at Sevastopol. Gameplay feedback supplied by the author remains distinct from
structural tests and generated-file verification.

Publication does not make independently built campaign mods additive.
Activate one complete campaign at a time unless a combination is verified.
Start a fresh campaign after an update. Voice recordings and editor publication
remain separate follow-up work.
