# Практические инструкции по созданию кампаний

[Начало работы](GETTING_STARTED_RU.md) · [Справочник полей YAML](YAML_REFERENCE_RU.md) · [English](RECIPES.md)

Выберите задачу в таблице. Каждая подробная инструкция начинается с простого рабочего примера, затем разбирает связанные изменения, настройки и ограничения текущего инструмента. Примеры предполагают независимую копию `campaigns/my-campaign`, созданную из комплектной кампании.

## Однократная подготовка

Установите окружение по инструкции «Начало работы». Откройте PowerShell в корне репозитория:

```powershell
$game = 'C:/Program Files (x86)/Steam/steamapps/common/WARNO'
./.venv/Scripts/python.exe -B scripts/campaign.py prepare --game $game
./.venv/Scripts/python.exe -B scripts/campaign.py clone campaigns/kacha campaigns/my-campaign --id my_campaign
```

Замените путь к игре своим. В новом окне PowerShell задайте `$game` заново. Для `clone` нужен новый каталог назначения. Сохраняйте исходную кампанию как образец.

## Проверяйте связанные изменения вместе

```powershell
./.venv/Scripts/python.exe -B scripts/campaign.py check campaigns/my-campaign --game $game --output artifacts/my-check-01
```

Для следующей попытки используйте новый каталог, например `my-check-02`. Команда подготавливает и проверяет исходные данные; кампанию не запускает и не устанавливает. После изменения английского имени или текста обновите все включённые таблицы `localization.yaml`.

## Соберите готовые исходники

```powershell
./.venv/Scripts/python.exe -B scripts/campaign.py build campaigns/my-campaign --game $game --output artifacts/my-build-01
```

Сборка выполняет штатную генерацию, запекание изменённой карты, обработку ресурсов и проверку полного пакета. Установка — следующий отдельный шаг из [подробной инструкции](recipes/14-build.ru.md). Проверяйте изменения в новой кампании: сохранение содержит прежние определения и состояние.

**Три уровня чтения:** этот навигатор → базовая процедура в начале отдельной инструкции → её настройки, устройство механизма и разбор ошибок. [Справочник YAML](YAML_REFERENCE_RU.md) содержит полную структуру файлов. Недокументированный ключ не создаёт новую возможность игры.
