# 12. Названия и переводы

[Навигатор](../RECIPES_RU.md) · [English](12-localization.md)

## Простой вариант: изменить предложение

1. Измените нужные text.ru/text.en события, слайда или меню.
2. В `localization.yaml` найдите **старую точную английскую строку** в каждой включённой таблице.
3. Замените ключ новой английской строкой и обновите перевод.
4. Выполните check, устраните отсутствующие строки и длинные короткие имена.
5. Соберите мод, откройте нужное окно новой кампании на соответствующем языке игры.

```yaml
text:
  ru: Резерв прибудет вечером.
  en: Reserves will arrive this evening.
```

```yaml
# В translations.fr; соответствующие записи исправляются и в других таблицах
"Reserves will arrive this evening.": "Les renforts arriveront ce soir."
```

Сохраните остальные записи и единственный блок translations. Ключ — английское содержимое, а не ID события.

```powershell
./.venv/Scripts/python.exe -B scripts/campaign.py check campaigns/my-campaign --game $game --output artifacts/localization-check-01
```

## Переименовать строку состава

У батальона измените definition.name и имеющееся name_text:

```yaml
name: Coastal Infantry Bn
name_text:
  ru: Береговой пехотный бат.
  en: Coastal Infantry Bn
```

Для других уровней используются organization_text, name_text роты/взвода, formation.division_text. Основные имена тоже остаются короткими. Явные локализованные поля самостоятельны: новая name при старом name_text может оставить старый экранный заголовок.

Для новой английской строки обновите все включённые ключи переводов. Уровни структуры — в [составе](03-rosters.ru.md).

## Языки и резервный английский текст

| Код YAML | Банк игры | Источник |
| --- | --- | --- |
| ru | RU | Непосредственные RU-поля; таблицы translations.ru нет |
| en | US и DEV | EN-поля, необязательная en-таблица базовых строк |
| fr | FR | translations.fr |
| de | GER | translations.de |
| es | SPA | translations.es |
| pl | POL | translations.pl |
| zh | SC | translations.zh |

Это семь языков и восемь банков. В YAML задавайте de, а не имя банка GER.

Корень localization.yaml: ровно schema 1, source_language en, translations. Таблицы связывают непустые английские строки с непустыми переводами. Каждая включённая неанглийская таблица покрывает весь необходимый словарь кампании. Недописанный французский перевод автоматически английским не дополняется.

Полностью отсутствующий язык использует английский fallback. Для RU/EN можно исключить localization.yaml либо целиком убрать необязательные языковые таблицы, не оставляя их частично заполненными. Такой мод не является полностью переведённым на отсутствующий язык. Необязательная en-таблица разрешает общие базовые строки без явных RU/EN-полей.

## Точное совпадение и YAML

Ключи чувствительны к регистру, пунктуации, пробелам и реальным переносам. Reserve и Reserves — разные строки. Ключи/значения с YAML-пунктуацией или словами, похожими на boolean/null, заключайте в кавычки. Повторные ключи отвергаются.

`>-` соединяет последовательные строки пробелами, `|-` сохраняет переносы. Отображаемая строка отличается от отступов исходника. Ключ перевода длинного блока должен совпадать с **прочитанным YAML** английским текстом. Ошибка отсутствующего перевода сообщает реально ожидаемую строку. Исправляйте соответствующее содержимое, а не предположительно сокращённое.

Штатное представление может объединять отдельные заголовок и текст. Переводчик разрешает многострочное объединение по абзацам; переводы исходных title/body всё равно нужны. Сохраняйте смысловые границы абзацев.

## Ограничение коротких имён

Имена батальонов, организаций, вышестоящих соединений, рот и взводов должны после перевода занимать **1–30 единиц UTF-16** на каждом языке. Пробелы/пунктуация учитываются. Обычно латиница/кириллица занимает одну единицу, многие дополнительные символы — две.

Для предлагаемого сокращения:

```powershell
$name = 'Coastal Infantry Bn'
$name.Length
```

.NET считает единицы UTF-16. Это удобная локальная проверка имени, а не замена полного check. Подбирайте понятное военное сокращение для языка, а не механически обрезайте слово или номер части.

Текст событий, вступления и меню имеет другие поля интерфейса: 30 единиц не распространяются на весь текст. Переведённое значение допускает до 20 000 знаков, но такой предел не гарантирует размещение в конкретном окне. Для карточек нужны короткие подписи, для слайдов — читаемые абзацы и просмотр результата.

## Форматирование и подстановки

- Сохраните каждое `%0`, `%1` и подобные обозначения с тем же количеством вхождений. Порядок может следовать грамматике.
- Сохраняйте штатные #US/#SOV и их порядок, если они есть.
- Значения непустые и без NUL.
- RU/EN-поля остаются обязательными при дополнительных таблицах.
- voice_script — подготовка дикторского текста, не обязательный экранный перевод или аудиофайл.

Проверяются подстановки и разметка коалиций, но не качество перевода, географическая терминология и понятность сокращений.

## Дополнительные сценарии

Одна исходная английская строка имеет общий перевод независимо от события. Для разных значений одного слова сначала задайте различающиеся английские формулировки. Чтобы добавить поддерживаемый язык, создайте полную таблицу, используя ошибки check и комплектный перевод как структурный образец.

Названия штатных тактических юнитов обычно предоставляет игра. Заголовки кампании, собственный текст и подчинение являются отдельной локализацией. Переименование роты не переименовывает все тактические карточки внутри неё.

## Устройство механизма

Компилятор собирает двуязычные строки и генерируемый словарь представлений, разрешает язык, записывает штатные словари и проверяет переведённые короткие имена. RU берётся непосредственно из полей, остальные языки используют английский ключ. Необъявленные таблицы дают fallback.

Поэтому английский ключ надо менять во всех включённых таблицах, а короткое исходное имя может оказаться недопустимо длинным только после перевода.

## Разбор проблем

Нет перевода: скопируйте точную ожидаемую строку из ошибки с её переносами. Русский состав в английском UI: проверьте явные name_text/organization_text/division_text и en. Длинный заголовок: сократите соответствующее разрешённое имя во всех таблицах и выполните check. Старый текст: установите полную новую сборку, начните заново. Ошибка форматирования: сохраняйте placeholders/разметку и правильно цитируйте YAML, а не удаляйте их.
