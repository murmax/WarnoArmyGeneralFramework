# 9. Авиация, аэродромы и уход авиакрыльев

[Навигатор](../RECIPES_RU.md) · [English](09-aviation.md) · [Состав](03-rosters.ru.md) · [События](06-events.ru.md)

## Простой вариант: изменить срок прибытия

1. В `aviation.yaml.wings` найдите крыло по `battalion`.
2. Измените `available.turn` на ход внутри кампании.
3. При наличии `withdraw_turn` сохраните уход позже прибытия.
4. Отдельно исправьте уведомление и переводы.
5. Выполните check/build и дойдите до срока в новой кампании.

```yaml
available: {turn: 5}
```

```powershell
./.venv/Scripts/python.exe -B scripts/campaign.py check campaigns/my-campaign --game $game --output artifacts/aviation-check-01
```

Дата находится в записи крыла, реальные самолёты — в его батальонном составе. Переименование не заменяет ни дату, ни технику.

## Создать ещё одно авиакрыло

Скопируйте полное самолётное определение под новым ID, например `my_strike_wing`. Подберите реальные packs и задайте:

```yaml
strategic:
  type: airplane
  battle_role: air_support
  visual: {unit: your_registered_strike_aircraft}
  aircraft_role: bomber
initial_state: {fatigue: 0}
```

Замените условный visual зарегистрированным юнитом. Блок находится внутри `definition`; сохраняются страна, имена, организация и непустые роты/взводы. У самолётных packs `transport: null`.

Привяжите определение к существующему дружественному аэродрому:

```yaml
- battalion: my_strike_wing
  airfield: your_existing_airfield
  available: {turn: 5}
```

Каждое самолётное определение должно иметь ровно одну запись авиации. Оно не может также находиться в deployments, наземных резервах, автоматических подкреплениях или эффектах event.spawn.

## Авиация после выбора

Для двухвариантного решения той же стороны:

```yaml
available: {event: air_support_choice, choice: 1}
```

Решение должно существовать; 1 — второй вариант. Используйте либо turn, либо event/choice, не оба сразу. Для альтернатив создавайте разные крылья и батальонные ID. Эффекты вариантов события могут быть пусты, когда их результат использует авиация.

При замене самолётов отдельно меняются реальные packs, роль, стратегический вид, имена, подчинение/эмблема, картинка решения и переведённое объяснение. Один параметр остальные не выводит автоматически.

## Потери и усталость прибытия

У крыла можно задать:

```yaml
initial_losses: {max_percent: 40}
```

Усталость находится в `definition.initial_state` батальона, например `fatigue: 6`. 0 — свежие, 8 — истощённые. Потери вычисляются как ограниченный бюджет состава, а не точный экранный процент. Отдельного `fatigue` в wings нет.

Самолётам генерируется штатная политика 4 начальных/4 восстанавливаемых ОД. Иное число в `definition.initial_state.action_points` не создаёт публичного механизма произвольных авиационных ОД.

## Уход авиакрыла

Добавьте каждому уходящему крылу:

```yaml
withdraw_turn: 15
```

Нужен известный более ранний срок прибытия. У доступности после выбора датированным должно быть решение. Уведомление об уходе — только представление; удаление выполняет поле самого крыла.

Можно убрать часть крыльев, сохранив остальные на том же аэродроме, например вывести истребители, но оставить штурмовую авиацию. Не удаляйте аэродром для имитации ухода. Публичный формат задаёт жизненный цикл авиакрыла, а не произвольное удаление наземных частей или модель повреждений авианосца.

## Новый аэродром или его перенос

Нужны все поля:

```yaml
- id: rear_airbase
  side: pact
  country: SOV
  position: [1267500, 695500]
  name: {ru: Тыловой аэродром, en: Rear Airbase}
```

Страна должна поддерживаться и входить в коалицию. Точка находится внутри игровой области. Нынешний адаптер допускает один авторский аэродром на сторону: для смены места изменяйте существующий, а не добавляйте второй той же стороне.

Вокруг точки нужен район размером в соседство одной штатной клетки, целиком внутри playable area. Не ставьте центр прямо на границу. Точка внутри полного profile.bounds ещё не гарантирует этого условия. Для тыловой базы можно выбрать удалённое от наземного фронта место.

Аэродром — штатное авиационное здание/место привязки, а не обычная захватываемая цель. Для контроля района отдельно объявите map-флаг и правило победы. Название «Цель» не делает аэропорт захватываемым.

## Все настройки

| Где | Допустимое значение / смысл |
| --- | --- |
| Корень | `schema: 1`, списки `airfields`, `wings` |
| `id` аэродрома | Уникальный строчный ID |
| `side` | `nato`/`pact` |
| `country` | Поддерживаемая страна стороны |
| `position` | Штатные `[x,y]` с внутригровым соседством одной клетки |
| `name` | Непустые RU/EN |
| `battalion` крыла | Уникальное полностью описанное самолётное определение |
| `airfield` | Существующий аэродром той же стороны |
| `available` | Точно `{turn}` или `{event,choice}` |
| Ход прибытия | Целое 1…длительность |
| Индекс выбора | Целое 0/1, действительное решение той же стороны |
| `initial_losses` | Необязательное точное `{max_percent}`, целое 0–99 |
| `withdraw_turn` | Необязательное целое внутри кампании, после датированного прибытия |
| `strategic.aircraft_role` | `fighter`, `bomber`, `sead` |
| `strategic.battle_role` | Для самолётов `air_support` |
| `strategic.icon` самолёта | Не задаётся: выводится из роли |
| Транспорт авиационного pack | `null` |

Истребительная роль требует зарегистрированных истребителей. Bomber принимает бомбардировщики/противотанковые самолёты. SEAD требует соответствующих тегов самолёта. Проверяется реальный состав/роль, а не только модель. Переименование истребителя в «ППВО» не даёт ему способности подавления.

Проверяйте tags в units.csv: fighter требует `Avion_Chasseur`, bomber допускает
`Avion_Bombardier` или `Avion_AT`, sead требует `Avion_SEAD`. Категория юнита
тоже должна быть airplane.

## Устройство механизма

Фреймворк создаёт штатные аэропорты и связывает с ними самолётные батальоны. Прибытия используют условия даты или выбора. Потери применяются однократно после создания.

У уходящей части есть уникальный runtime-тег. Удаление находит сохранившуюся соответствующую авиацию, а не полагается только на первоначальный результат создания. Аэродромная механика и подбор авиации для боя остаются штатными. Роль sead не гарантирует автоматического выбора ППВО ИИ для каждого защищённого боя.

## Разбор ошибок

Непривязанная авиация: добавьте запись wings. Чужая сторона: согласуйте решение, определение и аэродром. Ошибка роли: выберите нужные теги реальных packs без транспорта. Граница аэродрома: перенесите всё соседство внутрь playable bounds. Крыло осталось после уведомления: задайте его withdraw_turn. Неверная символика: отдельно проверьте страну и formation.emblem. Для изменённых крыльев начинайте новую кампанию.
