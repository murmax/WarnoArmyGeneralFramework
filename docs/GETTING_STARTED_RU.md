# Как пользоваться WARNO Army General Framework

## Если вы хотите играть

Готовая кампания распространяется как самостоятельный мод. Подпишитесь на неё
в Workshop, дождитесь скачивания, включите мод в WARNO и начните новую кампанию
Army General. Python, исходники и отдельный загрузчик игроку не нужны.

[Кача: оборона Севастополя](https://steamcommunity.com/sharedfiles/filedetails/?id=3811284575)
— пример кампании на новой карте. До открытия видимости автором предмет может
быть доступен только владельцу. Одновременно включайте одну кампанию этого
фреймворка: разные моды могут заменять одни и те же глобальные ресурсы игры.
Старые сохранения не получают новое расписание событий и подкреплений.

## Если вы хотите создать кампанию

Публичный релиз содержит Python-фреймворк и работу через YAML/CLI. WPF-редактор
будет опубликован отдельно после ручной проверки интерфейса. Его приложение
и исходники не входят в этот релиз; наличие команды с префиксом `editor-`
не означает, что редактор установлен.

Нужны Windows, Python 3.11+ и установленная WARNO с официальными инструментами
моддинга. Проверенная конфигурация — стандартный путь Steam и ModGen 201602.
Некоторые адаптеры пока привязаны к этому пути и версии ресурсов. Вариант с
другим расположением игры требует дополнительной проверки и адаптации.

### Подготовка

```powershell
git clone https://github.com/murmax/WarnoArmyGeneralFramework.git
cd WarnoArmyGeneralFramework
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
$game = 'C:\Program Files (x86)\Steam\steamapps\common\WARNO'
.\.venv\Scripts\python.exe -B scripts/prepare_game_template.py $game
.\.venv\Scripts\python.exe -B scripts/bootstrap_authored_localisation.py artifacts/full-campaign-work/RedLine1989-v12
```

Все команды выполняются из корня репозитория. Подготовка извлекает каталог
ModGen и создаёт локальные словари совместимости в `artifacts/`. Она не
запускает игру и не устанавливает мод. Повторный запуск в существующую папку
отклоняется, чтобы не затереть подготовленные данные. Разместите репозиторий
на диске с местом для рабочих сборок; не добавляйте `artifacts/` в Git.

### Два примера

`canvas-regression` показывает небольшое логическое поле новой карты. Его
можно проверить компилятором; для игры такой карте ещё нужна подготовленная
геометрия и текстура мира.

```powershell
.\.venv\Scripts\python.exe -B -m warno_ag campaign-compile campaigns/canvas-regression profiles/canvas-8x8.yaml artifacts/canvas-compiled
```

`red-line-demo` использует установленную географию Bruderkrieg и содержит
батальоны, события, авиацию и подкрепления. Это технический пример структуры
кампании, а не готовая сбалансированная игра. Для собственной работы скопируйте
пример в новую папку и назначьте отдельный `campaign.id`.

### Где редактировать данные

| Файл | Что задаёт |
| --- | --- |
| `campaign.yaml` | Название, стороны, время, правила победы и общую политику ИИ |
| `map.yaml` | Флаги, подписи, точки, источники влияния и клетки местности |
| `battalions/*.yaml` | Роты, взводы, командование, состав, опыт и принадлежность |
| `deployments.yaml` | Стартовые позиции, состояние, ОД и блокировку по ходам |
| `ai.yaml` | Приказы стартовым подразделениям |
| `production.yaml` | Соединения и сгруппированные волны подкреплений |
| `reinforcements.yaml` | Автоматические появления с датой и приказом |
| `events.yaml` | Условия, тексты, варианты выбора и последствия |
| `aviation.yaml` | Аэродромы и сроки доступности/вывода авиагрупп |
| `packs.yaml` | Необязательные собственные сочетания юнита, транспорта и опыта |
| `cinematics.yaml` | Необязательные вступления и условные окончания |

Не все примеры используют все документы. Сохраняйте отдельные RU/EN тексты,
короткие цели для игрового HUD и отдельное подробное описание в меню.
У каждого нового релиза должна быть проверенная полная сборка.

В версии 1.0.1 блокировка частей сохраняет штатный максимальный запас ОД.
Перед запуском логики кампании и на заблокированных ходах обнуляются только
текущие ОД. После снятия блокировки они восстанавливаются каждый ход обычным
способом. Старые сохранения с ошибочным максимумом 0/0 не исправляются:
начните новую кампанию после обновления мода.

Для остальных языков добавьте `localization.yaml` рядом с `campaign.yaml`:

```yaml
schema: 1
source_language: en
translations:
  fr:
    "Locked for %1 turns": "Bloqué pendant %1 tours"
```

Это пример формата, а не полная таблица: каждый объявленный язык должен
покрывать все экранные тексты кампании. Ключ — точная английская строка.
Коды таблиц: `fr`, `de`, `es`, `pl`, `zh` (упрощённый китайский).
Необязательная таблица `en` исправляет английские отображаемые названия.
Русский берётся из исходных полей `ru`. Переводятся меню, цели, события,
варианты выбора, вступления и окончания, подписи карты, соединения,
батальоны, роты и взводы. Компилятор отклоняет пропущенные строки и изменения
параметров `%1` или тегов коалиции. Без каталога переводов сохраняется прежняя
подстановка английского текста. Тексты для озвучки не создают записи автоматически.

Для приказов с обновлением по ходам и непрерывными маршрутами доступны
`retain_route_progress: true` и `aggressive_until: {nato: 9}`.
Первая настройка запоминает промежуточные позиции после установления контроля
армии: их повторная потеря не возвращает наступающие группы назад. Это память
закреплённых позиций, а не журнал движения каждого батальона. Конечная цель
остаётся доступной для повторного захвата.
Вторая назначает атакующим приказам НАТО штатный профиль `Agressif` на ходах
1–9, с `Default` начиная с хода 10. Приказы СССР и оборонительные/вспомогательные
задачи сохраняют `Default`. Общие пороги игры не меняются. Профиль допускает
менее выгодный прогноз боя, но не заставляет движок принять любую атаку.

`scripts/workshop_content_update.py` обновляет файлы и превью существующего
предмета Workshop через уже авторизованный клиент Steam. Он проверяет
владельца и сравнивает название, описание, видимость и теги до и после
загрузки, не отправляя изменения этих полей. Используется DLL из установленной
игры; она не входит в исходники фреймворка. Пароли скрипт не принимает.

### Полная сборка

```powershell
.\.venv\Scripts\python.exe -B -m warno_ag editor-public-package campaigns/red-line-demo profiles/bruderkrieg-map.yaml $game artifacts/demo-package --workspace-parent artifacts
```

Команда создаёт отдельный workspace официального компилятора, запускает его
без игрового окна, запекает ресурсы и проверяет комплект. Она не устанавливает
его. Для собственной географии и картинок добавьте подготовленные
`--world-source` и `--event-images`; формат и ограничения описаны в
[английском руководстве](GETTING_STARTED.md).

Результат `campaign-compile` сам по себе не является модом. Для установки
нужны путь к полному bundle и путь к compiled config, выведенные полной сборкой.

```powershell
.\.venv\Scripts\python.exe -B -m warno_ag full-install <bundle> <compiled-config>
.\.venv\Scripts\python.exe -B -m warno_ag full-activate <compiled-config>
.\.venv\Scripts\python.exe -B -m warno_ag full-status <compiled-config>
```

Закройте WARNO перед установкой. Для обновления управляемого мода используйте
`full-reinstall <новый-bundle> <новый-config>`. Не накатывайте отдельные файлы
поверх старой версии. Не используйте сохранение старой кампании для проверки
новых стартовых данных.

### Workshop

Готовый мод включает необходимый результат работы фреймворка. Отдельная
установка фреймворка на компьютере игрока не требуется. Экспорт в Workshop
не загружает файлы автоматически: сначала проверяется отдельный stage,
затем выполняется загрузка через официальный инструмент/SteamCMD.

Для приватной публикации в репозитории есть `private_workshop_release.py`
и `Run-PrivateWorkshopUpload.ps1`. Первый новый предмет получает ID; обновления
используют тот же ID и подтверждённый `publication.json`. Пароль и Steam Guard
вводите только в локальном окне SteamCMD. Полная последовательность приведена
в [разделе Workshop](GETTING_STARTED.md#prepare-a-self-contained-workshop-mod).

### Проверка и ограничения

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

Часть интеграционных тестов требует локальных игровых фикстур. Их отсутствие
отмечается как `skip`, а не как успешная проверка. Структурная проверка и
контрольные суммы не доказывают интересный баланс или правильное поведение
ИИ в игре. Проверьте обе стороны, несколько веток событий и окончания.

Фреймворк предназначен для обычных кампаний. Создание учебной кампании в меню
обучения, подсветка UI и запрет действий ради уроков не входят в задачу.
